# DNS Records to Add for careflowai.veraldlabs.co.uk
# Provider: Railway.cloud
# Target: cname.railway.app

## Add these DNS records at your domain registrar (veraldlabs.co.uk)

### Record 1: Frontend Subdomain
Type: CNAME
Name: careflowai
Value: cname.railway.app
TTL: 3600

### Record 2: Backend API Subdomain
Type: CNAME
Name: api.careflowai
Value: cname.railway.app
TTL: 3600

---

## What These Records Do:
- careflowai.veraldlabs.co.uk → Frontend (Next.js app)
- api.careflowai.veraldlabs.co.uk → Backend API (FastAPI)

---

## Step-by-Step Instructions for Common Providers:

### Option 1: GoDaddy
1. Login to https://www.godaddy.com/
2. Go to "My Products" → "DNS Management"
3. Find veraldlabs.co.uk and click "Manage"
4. Click "Add" or "Add Record"
5. Add the two CNAME records above

### Option 2: Namecheap
1. Login to https://www.namecheap.com/
2. Go to "Domain List" → click "Manage" next to veraldlabs.co.uk
3. Go to "Advanced DNS" tab
4. Click "Add New Record"
5. Add the two CNAME records above

### Option 3: Cloudflare
1. Login to https://dash.cloudflare.com/
2. Select veraldlabs.co.uk
3. Go to "DNS" → "Records"
4. Click "Add Record"
5. Add the two CNAME records above

### Option 4: Your Hosting Provider (ProSiteHosting)
1. Login to your hosting control panel
2. Go to "Domains" → "Manage DNS" or "DNS Zone Editor"
3. Add the two CNAME records above

---

## After Adding DNS Records:

1. **Wait for propagation** (10-30 minutes, up to 48 hours)
2. **Verify DNS** at: https://dnschecker.org/
   - Enter: careflowai.veraldlabs.co.uk
   - Should show: cname.railway.app

3. **Test** (after propagation):
   ```bash
   # Windows
   nslookup careflowai.veraldlabs.co.uk

   # Or use online tool
   https://dnschecker.org/
   ```

---

## Next: Deploy to Railway

Once DNS is configured, deploy to Railway:
1. Go to https://railway.app/
2. Create project from GitHub repo
3. Add custom domains: careflowai.veraldlabs.co.uk and api.careflowai.veraldlabs.co.uk
4. Railway will automatically provision SSL certificates

---

## For Google Search Indexing:

After deployment is complete:
1. Submit to Google Search Console: https://search.google.com/search-console
2. Add sitemap: https://careflowai.veraldlabs.co.uk/sitemap.xml
3. Google will discover the site through links and DNS propagation

Note: Google typically finds new sites within a few days to weeks after deployment.
